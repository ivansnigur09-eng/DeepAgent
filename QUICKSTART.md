# DeepAgent Quick Start Guide

## 🚀 Швидкий Старт (5 хвилин)

### Крок 1: Завантажити APK
1. Перейдіть на https://github.com/ivansnigur09-eng/DeepAgent/actions
2. Виберіть останній успішний workflow
3. Завантажте `deepagent-debug.apk`

### Крок 2: Встановити
1. Увімкніть "Встановлення з невідомих джерел" на Android
2. Встановіть APK
3. Запустіть DeepAgent

### Крок 3: Активувати
1. Згенеруйте invite код:
```bash
python3 invite_token_generator.py
```
2. Введіть код в додатку
3. Готово! ✅

## 💰 Як Почати Заробляти

### Trading Bot (Найпростіше)

**Що потрібно:**
- Binance API ключ (безкоштовно)

**Як налаштувати:**
1. Створіть Binance акаунт: https://www.binance.com
2. Згенеруйте API ключ (Settings → API Management)
3. В DeepAgent: Settings → API Keys → Add
   - Name: `binance`
   - Key: `ваш_api_ключ`
4. Long-press на кнопку Settings → Revenue Dashboard
5. Натисніть "Start Trading Bot"

**Що робить бот:**
- Моніторить ціни криптовалют 24/7
- Виявляє арбітражні можливості
- Показує trading signals з очікуваним прибутком
- **НЕ торгує автоматично** (для безпеки)

**Очікуваний дохід:**
- Перший тиждень: $0-50 (навчання)
- Перший місяць: $100-500 (з мануальним trading)
- Через 3 місяці: $500-2000 (з досвідом)

### Voice Commands (AI Асистент)

**Команди українською:**
- "Торгувати" → Запуск trading bot
- "Знайти роботу" → Пошук на Upwork (скоро)
- "Аналізувати" → Аналіз екрану
- "Дохід" → Показати заробіток
- "Допомога" → Список команд

**Команди англійською:**
- "Trade" → Start trading bot
- "Find job" → Search Upwork
- "Analyze" → Analyze screen
- "Revenue" → Show earnings
- "Help" → List commands

---

### Screen Analysis (Розумний Екран)

**Що вміє:**
- Читає текст з екрану (OCR)
- Розпізнає об'єкти
- Виявляє можливості заробітку
- Автоматично аналізує контент

**Як використовувати:**
1. Settings → Enable Screen Monitoring
2. Дайте дозвіл на захоплення екрану
3. AI автоматично аналізує що ви бачите
4. Отримуйте insights про можливості

**Приклади:**
- Бачите ціну криптовалюти → AI перевіряє арбітраж
- Відкрили Upwork → AI аналізує прибутковість job
- Переглядаєте товар → AI оцінює dropshipping потенціал

## 🔐 Безпека

### API Ключі
- Зберігаються в Android Keystore (hardware-backed)
- Шифруються AES-256-GCM
- Ніколи не передаються третім особам

### Trading
- Бот **НЕ** торгує автоматично
- Всі операції потребують підтвердження
- Risk management вбудований
- Stop-loss рекомендації

### Дані
- Все зберігається локально
- Differential privacy
- Federated learning (дані не покидають пристрій)
- GDPR compliant

## 🆘 Troubleshooting

### Бот не запускається
1. Перевірте Binance API ключ
2. Перевірте інтернет з'єднання
3. Перезапустіть додаток

### Немає signals
- Це нормально! Арбітраж рідкісний
- Зазвичай 1-5 signals на день
- Якість > кількість

### Voice не працює
1. Дайте дозвіл на мікрофон
2. Перевірте мову системи
3. Говоріть чітко і голосно
